# Веб-приложение с интеграцией базы данных Supabase

**Описание проекта:** 
Закрытое веб-приложение, разработанное на JavaScript. Реализована система безопасной авторизации, личные кабинеты и динамическая синхронизация с облачной базой данных Supabase.

## Реализованный функционал:
* **Фронтенд:** Адаптивная верстка (HTML/CSS) и интерактивная логика на JavaScript.
* **Авторизация:** Безопасный вход и регистрация пользователей по паролю через Supabase Auth.
* **Работа с данными:** Создание таблиц, безопасное хранение данных и вывод динамической информации на экран.
